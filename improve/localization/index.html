Community localization

Help translate Fieldbox

Fieldbox is built for photographers working everywhere. Community translators can help make its interface clearer and more useful in more languages.

Open the Fieldbox project on Crowdin ↗

How you can help

  • Translate Fieldbox interface text into a language you know well.
  • Review wording for clarity, consistency, and photography context.
  • Leave a comment when a source phrase needs more context.

How it works

English source text is maintained with the app. Crowdin hosts community translations and reviews. Approved translations return to the Fieldbox project for automated checks and in-app review before a language is released.

What the project contains

The public Crowdin project contains Fieldbox interface text prepared for localization. It does not contain your photos, filenames, sessions, hashes, storage accounts, credentials, telemetry, or other app data.

Contributions are reviewed before release. A translation may be adjusted for terminology, layout, accessibility, placeholders, or consistency with the rest of the app.
