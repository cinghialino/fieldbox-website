Know what is happening

Every file gets an outcome before the copy begins.

Fieldbox scans the card first. Review what is selected, what was already verified in this session, and what you excluded. RAW photographs, stills, video, audio, and sidecars can stay together as one shoot.

  • Choose by file or file type
  • Combine cards from the same job
  • Use saved naming and endpoint settings

Proof you can read

Current copy status, from device to cloud.

Fieldbox keeps local verification separate from endpoint confirmation. The session shows what was scanned, copied, verified, excluded, and reported by each connected provider.

Backup Status turns green only when the device has every verified file, one complete confirmed provider is offsite, and the session meets Fieldbox’s defined 3-2-1 conditions.

Fieldbox Pro

When the backup becomes a production workflow.

Start with the verified card-to-archive workflow. Add Pro when the job needs more endpoints, faster review, prepared sessions, working copies, or client delivery.

Pro

Send the session to more than one endpoint.

Use multiple cloud or NAS endpoints and concurrent uploads. Supported services include Dropbox, Google Drive, OneDrive, S3-compatible storage such as Backblaze B2 and Wasabi, and WebDAV/NAS.

Pro

Move from backup to review without waiting for the studio.

Create custom PDF contact sheets from a Fieldbox session. In 1.7.5, Pro can also build them directly from folders on connected storage, with folder and file-type grouping, without importing the originals.

Pro

Prepare the workflow before the card arrives.

Plan sessions, reuse source profiles, and create working copies for the next stage of the job. Pro also adds archive management and USB client delivery for one or more verified sessions.
